# BEST Voice TH Portable

โปรแกรมสร้างและโคลนเสียงภาษาไทยแบบ Offline สำหรับ Windows

## เป้าหมาย
- แตก ZIP แล้วเปิด `BEST Voice TH.exe`
- ไม่ต้องติดตั้ง Python หรือ PyTorch
- ONNX Runtime: CPU และ DirectML
- Voice Profile, ประวัติ, เล่นเสียง, Export WAV
- ไม่มี API, เครดิต หรือระบบสมาชิก

## สถานะ
Windows build จะสร้างโมเดล ONNX จาก checkpoint ภาษาไทยที่ได้รับอนุญาตใน GitHub Actions และทดสอบการสร้าง WAV ก่อนเผยแพร่ artifact
